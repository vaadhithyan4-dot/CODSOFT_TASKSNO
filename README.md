## 📊 Projects Completed

### Task 1 — Titanic Survival Prediction

**Objective**

Build a machine learning model to predict whether a passenger survived the Titanic disaster based on passenger information.

**Work Performed**

- Loaded the Titanic dataset using Pandas.
- Handled missing values.
- Removed unnecessary columns.
- Encoded categorical variables.
- Split the dataset into training and testing sets.
- Built a Random Forest Classifier.
- Predicted passenger survival.
- Evaluated the model using accuracy and classification metrics.

**Machine Learning Technique:** Random Forest Classification

### Task 2 — Movie Rating Prediction

**Objective**

Build a machine learning model that predicts movie ratings using information such as genre, director, actors, and other movie features.

**Work Performed**

- Loaded the IMDb movie dataset.
- Performed data cleaning and preprocessing.
- Handled missing values.
- Converted categorical features into numerical values.
- Performed exploratory data analysis.
- Split the dataset into training and testing sets.
- Built Linear Regression and Random Forest Regression models.
- Predicted movie ratings.
- Evaluated models using MAE, MSE, and R² score.
- Compared actual and predicted ratings.
- Analyzed feature importance.

**Machine Learning Technique:** Random Forest Regression

### Task 3 — Iris Flower Classification

**Objective**

Develop a machine learning model that classifies Iris flowers into three species:

- Iris Setosa
- Iris Versicolor
- Iris Virginica

The classification is based on sepal and petal measurements.

**Work Performed**

- Loaded the Iris dataset.
- Prepared the features and target variable.
- Split the dataset into training and testing sets.
- Built a Random Forest Classifier.
- Predicted flower species.
- Evaluated model accuracy.
- Generated a classification report.
- Created a confusion matrix.
- Analyzed feature importance.
- Tested individual flower predictions.

**Machine Learning Technique:** Random Forest Classification

### Task 4 — Sales Prediction

**Objective**

Build a machine learning model to predict product sales based on advertising expenditure across different platforms.

**Work Performed**

- Loaded the advertising dataset.
- Examined the dataset structure.
- Checked for missing values.
- Performed statistical analysis.
- Analyzed feature correlations.
- Split the dataset into training and testing sets.
- Built a Random Forest Regression model.
- Predicted sales.
- Evaluated the model using MAE, RMSE, and R² score.
- Compared actual and predicted sales.
- Analyzed feature importance.

**Machine Learning Technique:** Random Forest Regression

### Task 5 — Credit Card Fraud Detection

**Objective**

Build a machine learning model capable of identifying fraudulent and genuine credit card transactions.

**Work Performed**

- Loaded the credit card transaction dataset.
- Examined the class distribution.
- Checked for missing values.
- Separated features and target.
- Split the dataset into training and testing sets.
- Addressed class imbalance using balanced class weights.
- Built a Random Forest Classifier.
- Predicted fraudulent and genuine transactions.
- Evaluated model performance using accuracy, precision, recall, and F1-score.
- Created a confusion matrix.
- Analyzed feature importance.
- Tested individual transactions.

**Machine Learning Technique:** Random Forest Classification

## 🚀 How to Run the Projects

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the repository

```bash
cd CODSOFT_TASKSNO
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

### 4. Activate the environment (Windows)

```bash
.venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

### 6. Launch Jupyter Notebook

```bash
jupyter notebook
```

Open the required task folder and run the notebook cells in order.
